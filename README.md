# Assignment 6. jQuery

Student: Ashkarbekova Parasat

## Description

A simple website that shows jQuery selectors, effects, DOM manipulation and animations.
Each part of the assignment is on its own page. Use the navbar to move between pages.

- Home - Task 0. Setup
- Part 1 - Task 1. Selectors and CSS
- Part 2 - Tasks 2-4. Hide/show, fade and slide effects
- Part 3 - Tasks 5-7. Add/remove elements, attributes, form
- Part 4 - Tasks 8-10. Animations
- Part 5 - Task 11. Accordion menu

1. Open the live site link above.

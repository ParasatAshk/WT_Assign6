What is jQuery?
jQuery is a JavaScript library. It makes work with HTML, events and animations easier.
What are effects?
Effects are methods like hide, show, fade and slide. They change how elements appear on the page.
What is animate?
The animate method changes CSS properties step by step, for example size, position and opacity.
